## 1. Notion 是什么：信息结构与核心对象

- **工作区（Workspace）**：组织/个人的顶层空间，包含所有页面、数据库、团队空间、成员、权限等。
- **页面（Page）**：一切内容的容器，可嵌套；页面由“标题 + 属性（可选） + 内容区块（Blocks）”组成。
- **区块（Block）**：页面内容的最小单元：文字、标题、列表、图片、数据库视图、嵌入、代码块等都是区块。
- **数据库（Database）**：结构化数据容器（表/看板/日历/列表/时间线/画廊等视图）；每一条记录本质上也是一个页面。
- **团队空间（Teamspace）**：在同一工作区下，将内容按团队/项目分区（常见于团队版）。
- **权限（Permissions）**：对页面/数据库/工作区层级授予查看/评论/编辑/完全访问等。
- **模板（Template）**：页面模板、数据库模板、按钮/自动化触发模板，用于复用结构。

## 2. 页面（Page）功能点与交互

### 2.1 创建页面的入口

- 左侧边栏：
    - **New page**（新建页面）
    - 在某个页面下点“+”创建子页面
    - 在某个数据库中新增一条记录（即新增页面）
- 右上角（或页面顶部菜单）：复制、移动、导出、分享等。

### 2.2 页面层级与移动

- 页面支持无限层级嵌套：父页面 → 子页面。
- **拖拽**侧边栏页面可改变层级（缩进到另一个页面下）。
- 页面菜单（…）常见操作：
    - Move to（移动）
    - Duplicate（复制）
    - Add to Favorites（收藏）
    - Copy link（复制链接）
    - Export（导出）
    - Archive / Delete（归档/删除）

### 2.3 页面内容编辑的“/ 命令”交互

- 在任意输入位置输入 `/` 打开区块选择器。
- 常用类别（典型）：
    - Basic blocks：Text、Heading、Page、To-do、Bulleted list、Numbered list、Toggle、Quote、Divider、Callout
    - Media：Image、Video、Audio、File、PDF
    - Embeds：Embed、Bookmark、Google Drive、Figma、GitHub、Maps、Miro、Whimsical 等（取决于支持）
    - Database：Inline database、Linked view of database
    - Advanced：Table of contents、Equation、Code、Synced block

### 2.4 文本与块级交互（编辑体验）

- **文本选中浮层**：加粗/斜体/下划线/删除线/代码/链接/颜色/评论等。
- **块级拖拽手柄（⋮⋮）**：
    - 拖拽排序、缩进/反缩进
    - Turn into（转换块类型）
    - Duplicate / Delete
    - Copy link to block（复制块链接）
    - Comment（对块评论）
- **多选块**：框选或 Shift 多选，然后整体移动/复制/删除/变更类型。

### 2.5 页面内引用与@提及

- `@` 可提及：页面、数据库、日期、人员（成员）、集成对象等。
- `[[` 通常快速创建/链接到页面。
- 典型交互：输入 `@2026-05-19` 选择日期 → 生成可点击日期块，支持提醒。

### 2.6 目录、折叠、同步区块

- **Table of contents**：基于页面标题层级自动生成目录。
- **Toggle / Toggle heading**：用于折叠内容，适合长文档。
- **Synced block**：
    - 原始同步块（Source）与引用（Reference）共享同一内容。
    - 常用于：统一公告、SOP 片段、公司政策等。

### 2.7 评论、讨论与版本

- 页面/块评论：
    - 评论区可@人，支持已解决（Resolved）
- Page history（页面历史）：
    - 回看编辑记录、恢复到某版本（权限/套餐相关）

### 2.8 分享与权限（页面层）

- Share 按钮：
    - 邀请成员/来宾
    - 设置权限：View / Comment / Edit / Full access
    - 公开分享（Publish to web）与链接访问（Link access）
- 常见交互细节：
    - 给子页面继承权限 or 单独设置
    - 提示“此人需要请求访问”时可一键批准

## 3. 区块（Blocks）大全与交互要点

### 3.1 基础文本块

- Text：普通段落
- Headings：H1/H2/H3（部分 UI 允许 H4）
- Quote：引用
- Divider：分割线
- Callout：带图标的提示块

### 3.2 列表与任务

- Bulleted list / Numbered list
- To-do：复选框任务
- Toggle list：可折叠列表
- 交互：
    - Enter/Tab/Shift+Tab 控制层级
    - 多行粘贴可自动转列表

### 3.3 表格与公式（页面中的简单表）

- Simple table（非数据库）：轻量表格
- 数据库表（见第 4 节）用于复杂数据与视图。

### 3.4 媒体与文件

- Image：拖拽上传/粘贴/URL
- Video / Audio / File / PDF
- 交互：
    - 点击预览
    - 可加说明（caption）
    - 可与页面正文混排

### 3.5 代码、数学、嵌入

- Code block：语言高亮
- Inline code：行内代码
- Equation：LaTeX
- Embed/Bookmark：外链卡片

### 3.6 布局

- Columns：多列排版（拖拽调整宽度）
- 分组：将区块拖入同一列形成布局

## 4. 数据库（Database）：功能点与交互（超重点）

> Notion 数据库 = “结构化属性 + 记录页 + 多视图 + 过滤/排序/分组 + 关系/汇总/公式”。
> 

### 4.1 数据库的两种形态

- **全页数据库（Full-page database）**：独占一个页面。
- **内联数据库（Inline database）**：作为一个区块嵌在页面中。

### 4.2 记录（Row）= 页面（Page）

- 点击任意一条记录进入其详情页。
- 详情页顶部是属性（Properties），下方是内容（Blocks）。
- 交互：在表格视图中展开（Open as page / Peek）等。

### 4.3 视图（Views）与典型交互

常见视图类型（版本/套餐可能不同）：

- Table（表格）：最通用
- Board（看板）：基于状态/选择属性分列
- Timeline（时间线）：基于日期范围/开始结束
- Calendar（日历）：基于日期属性
- List（列表）：更适合阅读
- Gallery（画廊）：卡片式展示

视图通用操作：

- View 切换：顶部标签或下拉
- 新建视图：Add a view → 选择类型 → 选数据源（同数据库）
- 视图级设置（常见）：
    - Filter（过滤）
    - Sort（排序）
    - Group（分组）
    - Properties（显示/隐藏列）
    - Layout（卡片预览字段、封面显示等）
    - Sub-items / Dependencies（若启用）

### 4.4 属性（Properties）类型（常见）

- Title（标题）
- Text（文本）
- Number（数字）
- Select / Multi-select（单选/多选）
- Status（状态：支持分组，如 Not started / In progress / Done）
- Date（日期/时间，可提醒，可范围）
- Person（人员）
- Files & media（文件）
- Checkbox（勾选）
- URL / Email / Phone
- Relation（关联其他数据库）
- Rollup（汇总关联数据库字段）
- Formula（公式）
- Created time / Last edited time（系统字段）
- Created by / Last edited by（系统字段）

交互细节：

- 新增属性：数据库右上角 Properties → Add property
- 重命名属性：点击列名/属性名
- 隐藏属性：视图设置中隐藏（不删除）
- 删除属性：会影响所有视图与所有记录，谨慎

### 4.5 过滤（Filter）交互

- 支持组合条件：AND/OR、嵌套条件（部分 UI）
- 常见操作：
    - “状态是 Done”
    - “负责人包含我”
    - “日期在本周/下周/过去 7 天”（相对日期）
    - “多选包含某标签”

### 4.6 排序（Sort）交互

- 单字段或多字段排序
- 典型：按日期升序 + 状态 + 优先级

### 4.7 分组（Group）交互

- Table/List/Board 常见：按 Status/Select/Person 分组
- 组内支持折叠、组汇总（如计数）

### 4.8 关系（Relation）与汇总（Rollup）

- Relation：
    - 建立数据库之间的“引用”
    - 可双向（创建时可选自动创建反向属性）
- Rollup：
    - 基于 Relation 抽取对方的属性
    - 支持聚合：Count、Sum、Average、Min/Max、Show original 等

### 4.9 公式（Formula）

- 用于：字段计算、文本拼接、日期差、条件逻辑、显示状态等。
- 常见交互：公式编辑器中选择属性、函数，实时预览结果。

### 4.10 模板（Database templates）

- 在数据库中创建记录时可选模板。
- 模板内可预置：
    - 页面正文结构（标题、清单、子数据库等）
    - 默认属性值（部分）
- 交互：New → 下拉 → 新建/管理模板。

### 4.11 数据库权限与共享

- 数据库本身可分享；记录页也可单独分享（但受父级影响）。
- 常见策略：
    - 数据库只允许少数人编辑；其他人只读
    - 用不同视图控制展示字段与筛选范围（但注意：视图隐藏字段不等于权限隐藏）

## 5. 搜索、导航与信息组织

### 5.1 全局搜索

- Ctrl/Cmd + P 或 Search
- 支持：按页面标题、正文、数据库记录等搜索
- 常见交互：
    - 最近访问
    - 过滤（类型/时间）

### 5.2 侧边栏与收藏

- Favorites（收藏）置顶常用页面
- Recent（最近）快速回到最近访问
- Private（私人）与 Teamspaces（团队空间）分区

### 5.3 链接、反向链接与图谱思维

- 页面链接（Link to page）与提及（Mention）
- 反向链接（Backlinks）：查看哪些页面提到了当前页面（UI 位置随版本不同）

## 7. 模板、按钮与自动化（按常见能力描述）

> 具体入口与能力会随套餐/版本变化。
> 
- **页面模板**：快速新建固定结构页面
- **数据库模板**：为记录预置内容与属性

## 11. 典型场景的“功能组合”示例（交互串联）

### 11.1 做一个任务管理系统

1) 建一个 Tasks 数据库（Table）

2) 属性：Status、Assignee、Due date、Priority、Project(Relation)

3) 建多视图：

- Board（按 Status）
- Calendar（按 Due date）
- Timeline（按周期）
- My tasks（过滤 Assignee = me）

4) 建模板：Bug/Feature/Chore

5) 用 Relation + Rollup 做 Project 汇总

### 11.2 做一个团队知识库（Wiki）

1) 建 Wiki 数据库（Gallery/List）

2) 每条记录为一篇知识文档

3) 用标签、多级目录与模板统一结构

4) 用 Synced block 维护通用政策/声明
